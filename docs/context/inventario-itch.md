# Inventário — jogos (atualizado 12/nov/2026)

Página: [pedrocaurio.itch.io](https://pedrocaurio.itch.io/). Colaboradora recorrente: **Juliana Acunha** (game design). Outros: Debs Carvalho, Luiz Henrique ("Ito"), Vitor Silva, mad, Monorelh4, "0utro".

**Papel do Pedro em todos os jogos: programador** (confirmado pelo Pedro em 12/nov/2026). Engines: Godot em todos, exceto Midnight Meow (Unity) e Mathias Shooter (Pyxel, engine retrô em Python).

## Ordem de destaque sugerida

1. **Molten Metal** — mais recente, premiado, código 100% do Pedro.
2. **Midnight Meow** — projeto mais maduro, maior escopo técnico (multiplayer).
3. **Mathias Shooter** — prova de fundamentos (engine sem física pronta).
4. Eco, Pétalas ao Vento, Asas Temperadas, The Symphony's Awakening — grade secundária.
